Multi-Gate Scorecard

Every submission passes through configurable gates. The unified scorecard combines all results into a single pass/warn/fail recommendation with certification levels.

Evaluation Gate

A/B test results — uplift, pass rates, statistical significance

Security Gate

Cisco AI Defense — prompt injection, data exfiltration detection

Quality Gate

LLM-powered review — coherence, coverage, clarity, feasibility

Behavioral Gate

Edge case evaluation — robustness under adversarial inputs

Gate modes: block (must pass), warn (advisory), disabled. Combination: all_pass, any_pass, or weighted.

Certification levels: Foundational → Trusted → Certified

Complete Observability

Every pipeline run is tracked end-to-end — from gate scores to LLM token usage.

Normalized Database

4 PostgreSQL tables: scorecards, gate results, certifications, and observability metrics. Query evaluation history with simple SQL.

Token & Cost Tracking

Real LLM token counts captured per pipeline run. Track prompt/completion tokens, model usage, and estimated costs.

MLflow Integration

Auto-logs experiments, metrics, tags, and artifacts. One experiment per submission, run comparison out of the box.

MinIO Artifact Storage

Reports, scorecards, security scans, and debug artifacts stored with full provenance.

Statistical Rigor

Every A/B evaluation includes proper statistical testing to avoid false conclusions.

Welch's t-test

Tests whether the mean reward difference between treatment and control is statistically significant.

Fisher's Exact Test

Tests whether the pass rate difference is significant using binary pass/fail counts.

Uplift & Pass Rates

Reports treatment vs control pass rates, uplift gap, mean reward, and confidence metrics.

Get Started

Submit a skill for evaluation in three steps.

1. Create your submission

my-skill/
  metadata.yaml          # name, eval_engine, gate_policy
  skills/
    SKILL.md             # your skill definition
  instruction.md         # task description (or let AI generate it)
  tests/
    test_outputs.py      # pytest verification tests

2. Push to the submissions repo

git clone https://github.com/RHEcosystemAppEng/skill-submissions.git
cp -r my-skill submissions/
git add submissions/my-skill && git commit -m "Submit my-skill" && git push

3. Pipeline runs automatically

The push triggers the evaluation pipeline. Results appear in the OpenShift console, PostgreSQL, MinIO, and MLflow.

Where Results Live

PostgreSQL

Evaluation runs, trials, scorecards, gate results, certifications, observability metrics — all queryable.

MinIO

report.json, report.md, scorecard.json, security scans, debug artifacts — full provenance per run.

MLflow

Experiment tracking with metrics, parameters, tags, and artifacts. Compare runs across submissions.
